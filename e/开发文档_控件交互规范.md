# SUIDesigner 控件交互开发文档 v2.0

## 一、概述

本文档定义 HTML 页面与宿主程序（易语言）通过 WebView2 交互的控件规范。

**核心原则：约定优于配置。标准 HTML 标签零属性即可自动识别，复杂控件声明式配置。**

---

## 二、属性规范

### 2.1 属性总览

| 属性 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `id` | 是 | 控件唯一标识，宿主通过此 ID 发送命令和接收事件 | `id="btnSave"` |
| `data-ctrl-type` | 否 | 精确控件类型，旧方案兼容。简单控件可不填，自动推断 | `data-ctrl-type="button"` |
| `data-type` | 否 | 基础控件类型，用于 CSS 样式定位 | `data-type="button"` |
| `data-name` | 否 | 控件中文名称，便于阅读和调试 | `data-name="保存按钮"` |
| `data-drag-type` | 否 | 拖拽类型标记，CSS 用于 WebView2 拖拽功能 | `data-drag-type="iconButton"` |
| `data-ctrl-id` | 否 | 已废弃，等同于 id | — |
| `data-ctrl` | 否 | **新：复杂控件容器声明** | `data-ctrl="listBox"` |

### 2.2 id 命名规范

- 必须唯一，不可重复
- 推荐格式：`英文名_序号`，如 `button_1`、`input_name`
- 用于宿主发送命令和接收事件上报

## 三、简单控件（零配置）

以下控件**只需标准 HTML 标签 + id 即可自动识别**，无需任何 data-* 属性。

### 3.1 按钮

```html
<button id="btnSave">保存</button>
<button id="btnCancel">取消</button>
```

### 3.2 输入框

```html
<input type="text" id="txtName" placeholder="请输入姓名" />
<input type="password" id="txtPwd" placeholder="请输入密码" />
<input type="number" id="txtAge" />
<input type="email" id="txtEmail" />
```

### 3.3 文本域

```html
<textarea id="txtDesc" placeholder="请输入描述"></textarea>
```

### 3.4 复选框

```html
<label><input type="checkbox" id="chkAgree" /> 同意协议</label>
```

### 3.5 单选框

```html
<label><input type="radio" id="rdoMale" name="gender" value="male" /> 男</label>
<label><input type="radio" id="rdoFemale" name="gender" value="female" /> 女</label>
```

### 3.6 下拉框

```html
<select id="selCity">
  <option value="bj">北京</option>
  <option value="sh">上海</option>
  <option value="gz">广州</option>
</select>
```

### 3.7 超链接

```html
<a href="#" id="linkMore">查看更多</a>
```

### 3.8 进度条

```html
<input type="range" id="progressBar_1" min="0" max="100" value="50" />
```

### 3.9 日期时间选择器

```html
<input type="datetime-local" id="dtPicker_1" />
<input type="date" id="datePicker_1" />
<input type="time" id="timePicker_1" />
```

### 3.10 开关切换

```html
<label id="switch_1">
  <input type="checkbox" />
  <span>开启通知</span>
</label>
```

### 3.11 图标按钮

```html
<button id="iconBtn_1"><i class="fas fa-star"></i> 收藏</button>
```

### 3.12 文本标签

```html
<span id="label_1">状态：运行中</span>
```

## 四、复杂控件（声明式配置）

复杂控件使用 `data-ctrl` 声明容器类型，桥接脚本自动渲染内部结构。

### 4.1 列表框

```html
<div data-ctrl="listBox" id="listBox_1"
     data-items='["项目一","项目二","项目三","项目四"]'>
</div>
```

**属性说明：**
| 属性 | 说明 |
|------|------|
| `data-items` | JSON 字符串数组，列表项文本 |
| `data-editable` | 可选，是否允许编辑，默认 `"false"` |
| `data-show-checkbox` | 可选，是否显示复选框，默认 `"false"` |

### 4.2 多项表格

```html
<div data-ctrl="dataGrid" id="dataGrid_1"
     data-columns='["姓名","年龄","城市"]'
     data-rows='[["张三","25","北京"],["李四","30","上海"],["王五","28","广州"]]'
     data-show-checkbox="true"
     data-editable="false">
</div>
```

**属性说明：**
| 属性 | 说明 |
|------|------|
| `data-columns` | JSON 字符串数组，列标题 |
| `data-rows` | JSON 二维数组，每行数据 |
| `data-show-checkbox` | 可选，是否显示行复选框，默认 `"false"` |
| `data-editable` | 可选，是否允许单元格编辑，默认 `"false"` |
| `data-allow-add` | 可选，是否允许添加行，默认 `"false"` |
| `data-allow-delete` | 可选，是否允许删除行，默认 `"false"` |

### 4.3 树形框

```html
<div data-ctrl="treeView" id="treeView_1"
     data-tree='[
       {"text":"根节点","children":[
         {"text":"子节点1"},
         {"text":"子节点2","children":[
           {"text":"孙节点1"},
           {"text":"孙节点2"}
         ]}
       ]}
     ]'
     data-show-icon="true"
     data-editable="false">
</div>
```

**属性说明：**
| 属性 | 说明 |
|------|------|
| `data-tree` | JSON 树形结构，每个节点包含 `text` 和可选的 `children` |
| `data-show-icon` | 可选，是否显示节点图标，默认 `"true"` |
| `data-editable` | 可选，是否允许节点编辑，默认 `"false"` |

### 4.4 标签页容器

```html
<div data-ctrl="tabs" id="tabsContainer_1"
     data-tabs='[
       {"title":"标签1","content":"<p>标签1的内容</p>"},
       {"title":"标签2","content":"<p>标签2的内容</p>"},
       {"title":"标签3","content":"<p>标签3的内容</p>"}
     ]'>
</div>
```

**属性说明：**
| 属性 | 说明 |
|------|------|
| `data-tabs` | JSON 数组，每项包含 `title` 和 `content`（HTML 字符串） |

## 五、旧方案兼容（完全兼容）

旧方案使用 `data-ctrl-type` + `data-type` + 完整 DOM 结构的方式**完全兼容**，无需修改。

```html
<!-- 旧方案按钮，仍然可用 -->
<button id="button_1" data-type="button" data-ctrl-type="button" data-ctrl-id="button_1" data-name="按钮_1">按钮</button>

<!-- 旧方案列表框，仍然可用 -->
<div id="listBox_1" data-type="listBox" data-ctrl-type="listBox" data-name="列表框_1" class="listBox_scroll">
  <div class="listBox_item" data-ctrl-type="listBox_item">列表项一</div>
  <div class="listBox_item" data-ctrl-type="listBox_item">列表项二</div>
</div>
```

## 六、宿主命令规范

### 6.1 命令格式

宿主通过 WebView2 发送 JSON 命令：

```json
{
  "command": "控件ID.方法名",
  "参数名": "参数值",
  "needResult": true
}
```

### 6.2 所有控件通用方法

| 方法 | 说明 | 参数 |
|------|------|------|
| `控件ID.getValue` | 获取控件当前值 | 无 |
| `控件ID.setValue` | 设置控件值 | `value` |
| `控件ID.enable` | 启用控件 | 无 |
| `控件ID.disable` | 禁用控件 | 无 |
| `控件ID.show` | 显示控件 | 无 |
| `控件ID.hide` | 隐藏控件 | 无 |
| `控件ID.setStyle` | 设置控件样式 | `style`: {css属性: 值} |
| `控件ID.focus` | 获取焦点 | 无 |

### 6.3 特定控件方法

#### 列表框

| 方法 | 说明 | 参数 |
|------|------|------|
| `listBox_1.addItem` | 追加一项 | `value`: 文本 |
| `listBox_1.removeItem` | 删除指定项 | `index`: 序号 |
| `listBox_1.clear` | 清空 | 无 |
| `listBox_1.setItems` | 替换全部数据 | `items`: JSON 数组 |

#### 表格

| 方法 | 说明 | 参数 |
|------|------|------|
| `dataGrid_1.addRow` | 追加一行 | `row`: JSON 数组 |
| `dataGrid_1.removeRow` | 删除指定行 | `index`: 序号 |
| `dataGrid_1.clear` | 清空 | 无 |
| `dataGrid_1.setRows` | 替换全部行数据 | `rows`: JSON 二维数组 |
| `dataGrid_1.setColumns` | 替换列定义 | `columns`: JSON 数组 |

#### 树形框

| 方法 | 说明 | 参数 |
|------|------|------|
| `treeView_1.addNode` | 添加节点 | `parentId`: 父节点ID, `text`: 文本 |
| `treeView_1.removeNode` | 删除节点 | `nodeId`: 节点ID |
| `treeView_1.setTree` | 替换全部树数据 | `tree`: JSON 树结构 |

#### 标签页

| 方法 | 说明 | 参数 |
|------|------|------|
| `tabsContainer_1.selectTab` | 切换标签页 | `index`: 序号 |
| `tabsContainer_1.addTab` | 添加标签页 | `title`: 标题, `content`: HTML内容 |
| `tabsContainer_1.removeTab` | 删除标签页 | `index`: 序号 |

### 6.4 返回值机制

需要获取返回值时，在命令中设置 `needResult: true`：

```json
{ "command": "input_1.getValue", "needResult": true }
```

宿主会收到回传消息：

```json
{
  "action": "cmdResult",
  "targetId": "input_1",
  "data": {
    "command": "input_1.getValue",
    "result": "用户输入的内容"
  }
}
```

## 七、事件上报格式

用户操作控件时，桥接脚本自动上报事件到宿主：

```json
{
  "title": "页面标题",
  "action": "click",
  "customname": "保存按钮",
  "targetId": "btnSave",
  "basictype": "button",
  "ctrlType": "button",
  "source": "native",
  "data": {
    "value": "保存",
    "mouse": "left",
    "x": 150,
    "y": 300
  },
  "timestamp": 1718425600000
}
```

**action 类型：**
- `click` — 单击
- `dblclick` — 双击
- `change` — 值改变
- `focus` — 获得焦点
- `blur` — 失去焦点
- `contextmenu` — 右键菜单

**source 标记：**
- `explicit` — 显式 data-ctrl-type 声明
- `native` — 原生 HTML 标签自动推断
- `container` — 复杂控件容器内子元素

## 八、AI 开发提示词模板

### 8.1 简单表单页

```
请生成一个 HTML 表单页面，包含以下控件（每个控件必须有唯一 id）：
- 一个文本输入框
- 一个密码输入框
- 一个复选框
- 一个下拉选择框
- 一个提交按钮

要求：
1. 使用标准 HTML 标签，不需要 data-* 属性
2. 每个控件必须有 id 属性
3. 引入 webviewBridge_v2.js 脚本
4. 样式使用内联或 <style> 标签
```

### 8.2 带表格的数据页

```
请生成一个 HTML 数据管理页面，包含：
- 上方一个搜索输入框和搜索按钮
- 下方一个数据表格

表格使用 data-ctrl="dataGrid" 声明式配置：
data-columns 定义列，data-rows 定义行数据

要求：
1. 每个控件必须有唯一 id
2. 引入 webviewBridge_v2.js 脚本
3. data-* 属性值使用 JSON 格式
```

### 8.3 带树形框的页面

```
请生成一个 HTML 文件管理页面，左侧使用树形框展示目录结构。
树形框使用 data-ctrl="treeView" 声明式配置，data-tree 定义树形数据。

要求：
1. 每个控件必须有唯一 id
2. 引入 webviewBridge_v2.js 脚本

```
